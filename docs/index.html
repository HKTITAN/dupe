one app, as many profiles as you need

Run Claude, ChatGPT, Grok Bot or any Electron app as separate, colour-coded copies. Each one keeps its own login, its own data and its own icon on the Dock or taskbar. Works on macOS, Windows and Linux.

Grown from Stephen Wu's macOS script, which clones the AI desktop apps into blue "Work" copies. Blue still means work.

recolour an icon

Drop any app icon and pick a colour. The page keeps the icon's lightness and detail and moves only its hue, or, for a grayscale mark, remaps its field to the colour and the mark to white. Nothing is uploaded.

build profiles

Pick an app, name the profile, choose its colour. The launcher, the recoloured icon and the Start Menu or Dock entry are built for you.

This page can't reach your computer

Building a profile means compiling a launcher and writing files next to the app, so it runs from your own machine. Install the tool, then open this same interface connected to it:

npm install -g dupe
dupe ui

Or skip the interface

dupe add claude work
dupe add chatgpt work
dupe add claude client-a --color green
dupe add /Applications/Slack.app personal

Presets: claude, chatgpt, grok-bot, slack, discord, notion, obsidian, vscode, cursor, chrome, edge, brave. Any other app works by path. Needs Node 20 or newer.

on your phone

Phones don't let one app clone another, so the answers there are settings, not code. The icon studio above still works on this device for custom launcher icons.

Android

A work profile is a second copy of every app with its own accounts and a badge on the icon. Set one up for yourself with Shelter, then clone Claude or ChatGPT into it. For more than 2 copies, most phones have an app-cloning setting.

iPhone and iPad

Add claude.ai or chatgpt.com to the Home Screen from Safari once per account. Since iOS 16.4 each copy is its own isolated web app with its own login and notifications. A Shortcut can carry a recoloured icon.
